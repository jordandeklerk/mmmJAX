# Analysis

With the model fitted, these pages start asking it questions, measuring what
each channel adds and returns and checking those answers against the
simulation's truth. They then optimize the budget, put the plans for the
current budget through the same check, and run scenarios on data you prepare.

| Guide | Description |
| --- | --- |
| [Media effects](media_effects) | Contributions, returns, and response curves from the fitted model |
| [Recovering the truth](recovery) | How close the fit's returns, contributions, and curves come to the simulation's truth, and what the data can't separate |
| [Budget optimization](budgets) | The split of a budget that maximizes expected revenue, and what the plans for the current budget gain in the simulation |
| [Scenarios](scenarios) | A forecast for next quarter from data you prepare, and two plans compared |
